# PR-07b6｜本机演员／场景／道具参考图库

## 交付给操作员的真实功能

Streamlit「资产与生产任务」页新增**本机人物 / 场景 / 道具参考图**：先选择本剧某条 `series_assets` 资产及其**确切版本**，再上传仅用于本机人工对照的 JPG/PNG/WEBP（每张最多 8 MiB），阅读并勾选素材原创权或使用许可的自述声明。支持一个资产版本逐次追加多张独立参考图、重新打开后显示缩略图库、在图下对照版本号和哈希；完全不修改现有资产文字规格、已有审核状态或镜头/模型任务。

**为何绑定到具体资产版本？** 同一系列中演员妆造、服装、场景布局可以追加新的 asset 版本（新 ID）。新版本**不会自动继承**旧版参考图，也不能从另一 Series 盗用同名角色参考图。重新核验时总是以当前 DB 资产的 `series_id / id / kind / version / specification_json SHA256` 为依据。

## 安全边界

- 原始上传文件仅在内存接受；校验 magic/实际文件格式、单帧、像素数不超过 1200 万、最长边不超过 4096；用 Pillow 原样转向并缩放至 1024 以内，再**创建新的 RGB PNG 像素文件**，不保存原图文件名、EXIF/GPS、ICC 或其他原始信息。每张最多留 20 个参考版本。
- 实际内容写入本机 `DRAMA_FACTORY_DATA_DIR/local-asset-references/<series_id>/<asset_id>/<source_sha256>.png`；同文件夹独立内容收据 `<source_sha256>.json` 记录哈希、所属资产的具体版本和操作者自述授权。文件写入使用不可覆盖的硬链接创建；重复上传相同字节幂等，新图只追加，旧参考图不会被覆盖。
- **每次展示前**检查 Series/Asset 归属、资产规格版本哈希、收据、PNG SHA256、尺寸与 PNG 解码。拒绝不可信路径、符号链接、损坏/篡改图片与跨剧读取；拒绝 `voice` 类资产，绝不把上传图像隐式作为人物声纹、AI 模型可用参考图或自动审核许可。
- 当前**只有本机的操作者权利自述**。没有商业授权合同核实、人脸肖像确认、批量照片病毒检测、媒体安全沙盒、用户登录、跨用户权限隔离、加密媒体库，**禁止公网开放**；不可在该原型处理不可信客户端或私人真人形象资料。无付费 Google 请求、云数据库、AI 角色生成、模型上传、声音处理。
- 图片始终留在本机数据目录，**禁止将用户上传的图片、真实人物脸、原著或缓存内容提交 Git/GitHub Actions**。

## 验收

`tests/test_local_asset_references.py` 只用 Pillow 生成完全合成图片，验证真实 JPG EXIF 字段清除与图片像素缩放、资产版本归属、追加与重复幂等、禁止跨 Series/声样类型、未勾选版权、扩展名不符、损坏/超大/动画、收据/P​​NG 篡改、根目录/收据符号链接，以及 UI Python AST 编译。

必须 Python 3.11/3.13、本地 libSQL、FFmpeg 离线 QA 四项 CI 全绿才合并。仅通过这些测试，不代表角色视觉一致性由模型验证，也不代表商业可用版权已被证明。
