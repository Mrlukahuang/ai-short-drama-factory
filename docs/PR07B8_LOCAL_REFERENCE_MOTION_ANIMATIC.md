# PR-07b8｜本机参考图 → 动态分镜片段 → 已审核整集 MP4

## 首次实现“镜头真的动起来”，但不冒充 AI 视频

在 Streamlit **「本机审片」** 的已完成两级人工审核的 Production 下，新增可展开的「从本机参考图制作动态分镜」面板。选择该镜头已批准的**演员或场景资产具体版本**，选取此前通过 PR-07b6 图片完整性校验的某张图，单独明确确认：**允许本机将这张静态参考图转换成模拟推镜运动的衍生技术样片**。若该镜头已有用户上传的视频，必须再次显式选择覆盖，不能偷偷把真素材替换为静帧。

使用本机 FFmpeg 在单个静态参考图上做慢速推镜（Pan/Zoom/Ken Burns），产生真正可解码的 360×640 / 15 fps / H.264 / 1–30 秒 MP4，嵌入英文防误认水印 **LOCAL REFERENCE / SIMULATED MOTION** 与 **NOT AI VIDEO / NOT FOR PUBLICATION**。动态片段可通过 PR-07b5 现有持久本机视频登记入口储存到具体 Series / Production / Shot，之后按原来的按钮一键交给 PR-11/07b1 离线渲染器，与其它动态视频或占位镜头一起生成整集 MP4，重新过字幕、媒体哈希和 FFmpeg 独立技术 QA。

## 关键门禁

- 必须是当前剧集已批准剧本及人物审批的 Production；镜头时长最多 30 秒，整集仍不超过 12 镜/90 秒。
- 参考图必须属于**此已批准镜头中的演员或场景具体资产 ID**；只接受图库已确认的 source_sha256，重新验证图库收据、文件 SHA256、像素和资产版本。不能拿另一个角色、场景、另一 Series 或任意磁盘路径作为镜头来源。
- 操作者需明确确认静态参考图的**本机衍生使用许可**；图库里最初的“仅供人工参考”的自述授权不能自动扩大为生成视频的许可；已有视频更要再勾选明确覆盖。
- 所有 FFmpeg 子进程都带固定滤镜和固定生成路径；不接收未信任 shell 命令、第三方 URL 或外部 API。临时图片与视频在独立临时目录中创建并销毁；仅经过复核的最终 MP4 被 PR-07b5 哈希仓持久登记。
- 这种画面不包含活人动作、口型同步、AI 视频模型、更不用说可公开发布的真人影视画面。它只是**带真实动态像素的可播放“动态分镜（animatic）”**。不会提高 `model_use_approved` 或 `publish_approved`，没有独立的真人肖像、版权许可审核。
- 无 Google 调用、无视频云存储，付费模型成本 **US$0**。主仓库和 CI 只使用程序化生成的彩色合成图，不上传用户上传的图片或人脸。
- 当前 Streamlit 和 FastAPI 本机原型仍无用户认证、媒体解码沙盒、抗病毒软件和访问控制：**严禁公网部署**。

## 真实 AI 模型的后续前置条件

已有 `GoogleImageProvider`、`FakeGoogleImageProvider` 及一次一张图的手动冒烟测试，但真实生成仍要求独立 API 密钥和手动付费授权，尚无可信供应商侧硬费用上限或跨企业版权保障。此次不修改或运行任何收费工作流，不解锁此前已消耗的一次性 TTS/TxLab Workflows。

## 验收

`tests/test_local_reference_animatic.py` 用 Pillow 生成非真人虚构彩色图、FFmpeg 实际生成 2 秒动态镜头，再通过真实 Production 两级审批门禁、PR-07b5 文件登记、原 `render_approved_preview` 真实整集 MP4、字幕和只读独立 QA。检查原视频替换需要显式确认、不批准 Production 不得制作、跨剧和非本镜头角色拒绝、缺失图片和图片篡改拒绝、零付费、成片仍不准发布。合并要求原四项 CI 全绿。
