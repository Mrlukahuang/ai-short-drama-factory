# PR-07b7｜导演逐镜头参考图片选择与相邻镜头对照

## 实际功能

在原有 Streamlit **「分镜与审批」** 页面中，针对已经**应用到草稿**的 Screenplay，新增可展开的「逐镜参考图选择 · 相邻镜头对照（本机）」：

- 选一个镜头，按该镜头明确登记的出场演员 ID、场景 ID，选择对应资产**具体版本**下的 JPG/PNG/WEBP 本地清洁参考图；可另外选最多 4 个同一 Series 的道具资产，作为**单纯导演注释**。道具不会被自动写入已审批剧本或视频。
- 图片来自 PR-07b6 已完成本机图库，**每次读取都重新验证 Asset/Series/版本/图片 SHA256 和安全解码**。选择由本人点击「保存这个镜头的参考选择」，需要单独勾选人工确认；不触发数据库审核、模型调用或商业发布。
- 选择绑定到 `SHA256(canonical Screenplay)`、本剧 Series ID、镜头 ID 和图片原始内容哈希。**剧本任何文字、动作、时长、演员、场景变化，都导致新草稿指纹，旧图片选择不会悄悄继承。** 重启本机 UI 后，仍可按同一草稿指纹恢复选择。
- 选镜头后，右侧/下方并排展示该镜头和其相邻镜头已经**明确保存的**真实参考缩略图。对相邻镜头沿用的同一个**资产版本**，如果只有一侧选图、或者两侧选了不同图，报告**建议人工复查**，换装或合理切场均可能合法；即使完全无提示也不构成质量/版权/人物识别验证。
- 保留原来导演镜头/对白时间轴、`/validate`、人工提交 Episode、剧本和人物审批、离线 FFmpeg 合成和技术 QA。此功能只有手工视觉对照，不改变这些关卡。

## 实现和边界

核心 `src/drama_factory/pipeline/shot_reference_board.py` 只访问本机 SQLite 资产归属、已经存在的本地图片图库及本地逐镜选择收据。收据目录 `DRAMA_FACTORY_DATA_DIR/local-shot-references/<series_id>/<screenplay_sha256>/<shot_id_sha256>.json`，单镜人工选择使用临时文件+原子替换持久保存；绝不直接保存用户原图、剧本文字或二进制图片副本。收据包含 `model_use_approved=false`、`publication_approved=false`，只表明操作员选择了某张图，不是已签署许可或安全模型参考帧。

加载时对每张图片重新执行 PR-07b6 的完整照片 SHA256、资产版本和文件解码核验；剧本重新经过本机结构校验和服务器同样的 Series/Bible/演员/场景归属判定。任何跨剧、伪造演员、非本镜头人物、声线资产、未登记图片、损坏图片、修改收据或符号链接均拒绝，而不是展示可能错配的头像。

**没有人脸识别/镜头内容理解、独立版权合同或肖像授权、用户登录、沙盒媒体隔离、真正的 AI 图像/视频生产。必须仅可信 `127.0.0.1` 本机环境，不能公开部署，也不能将私有人脸等资料上传至 GitHub。**

## 验收

新增 `tests/test_shot_reference_board.py`：通过 Pillow 合成假参考图，验证指定镜头的真实 PNG 数据显示、不同镜头同资产选择不同参考图触发提示、明确清除、修改草稿后不沿用旧选择、道具仅为额外注释、跨剧集/错场景/非法 Voice/缺失图片/未人工确认拒绝、恶意收据、源图片篡改、符号链接和 Streamlit 前端 AST。

CI 目标仍是 Python 3.11、3.13、真实本地 libSQL、真实 FFmpeg offline-video **四项全绿才允许合并**。模型费用为 US$0，数据库 schema 不变。
