# PR-07b4｜导演镜头／对白时间轴与跨镜连续性复查（本机只读）

## 目标：从分镜列表进化为可用的导演时间轴

在 Streamlit「分镜与审批」→「导演时间轴」里，新加两条互相对应的静态时间轴：

1. **镜头时间轴**：每镜精确整数秒起止、镜号、时长、场景、出镜人物和摄影方式。横向条块的长度代表镜头的真实时间；下面显示开镜/收镜状态，便于审核接戏。
2. **对白时间轴**：每条有说话人归属和所在镜头的真实全片时间区间。导演手动填写的起止秒标为「导演明确填写」；尚未定时的对白按照现有 FFmpeg/离线多角色音轨同样的整数秒均分算法显示，并清楚标记「离线技术均分（未经导演批准）」。演员变更不会篡改已批准的对白。
3. **人工复查提示**：上一镜结束状态与下一镜开头状态不一致（仅比较去除多余空格与大小写后的文本）、尚未填写的原型模板、场景 ID 变化、演员集合变化、未定时对白多于镜头整数秒这五类场景。状态不同**可能只是正常剪辑**，不会自动认定穿帮、不能阻断正常提交，更不会擅自修正剧本。

时间轴只读取**最后已经按「应用修改到草稿」保存的草稿版本**。在编辑表单中尚未应用的修改不会渲染于旧时间轴，也不能自动取得验证或批准。结构校验和 12 镜/90 秒本机预览上限由纯 Python `director_timeline` 控制；继续通过原 `/validate` 和 `/commit`、两个 Production 人工批准及完整 FFmpeg QA。

## 安全与真实性

- 不创建额外付费模型接口、AI 图像/声音/视频生成、Google/Turso 请求或公网媒体分享；全程离线零美元。
- `src/drama_factory/pipeline/director_timeline.py` 无任何数据库、文件、网络、审批调用；原始剧本不会被函数修改。
- `approval_granted=False`、`publish_approved=False`、`human_continuity_review_required=True` 始终成立，**零提示不等于服装、道具、口型、镜头轴线或版权已审过**。
- 当前仅属 **127.0.0.1 无认证的开发用工作台**，禁止公网开放。实际商业发行仍需权限、脸/声/图像许可、真实模型试片和账单实测。
