## 故事核心

一家人周末清单很长，钱包只有几枚 CD 金币；CityDiscount 吉祥物背起包，用探测器穿越奥克兰寻找并整理买菜、吃喝、购物、出游的示意折扣，送回寻宝地图；一家人实现生活心愿，钱包还有 CD 金币留给下一次快乐。

1. 0–10 秒：周末清单与钱包的小烦恼；CityDiscount 吉祥物主动接任务
2. 10–35 秒：奥克兰寻宝，四站寻找买菜/美食/购物/出游示意折扣
3. 35–45 秒：查看使用条件、分类整理，折扣册变地图并送回家庭
4. 45–60 秒：一家人丰富周末、CD 金币有余、品牌 Logo 定格与关注 CTA

**情绪：** 品牌毛毡微缩城市寻宝动画。观众希望感觉到吉祥物认真帮忙、奥克兰生活丰富、关注 CityDiscount 值得。**目标口号：**我们到处找，你轻松发现。
